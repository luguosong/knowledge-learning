# 机器记录为唯一事实源，人类站点为派生视图

知识库存有两类产物：给 agent 的机器记录（`提问记录/`）与给人的人类站点（`站点/`，zensical 构建、GitHub Pages 发布）。两类产物独立演化必然漂移，故决定机器记录是唯一事实源，站点文章是派生视图——只依据记录与当次对话生成，不引入记录外的结论，可随时整体删除重建；整理代理更新文章时伴随拆分与合并判断，但结构与内容有疑问时以记录为准。

## Considered Options

- 双写自由演化（文章可独立补充记录之外的内容）：拒绝——漂移无法审计，站点重建即失真。
- 只留站点、废弃机器记录：拒绝——agent 检索、沉淀与证据链依赖记录结构。
