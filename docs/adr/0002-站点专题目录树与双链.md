# 站点采用专题目录树与双链，文章经裂变自相似生长

[ADR-0003](0003-主题文章作为唯一正文.md) 确认主题文章为唯一正文，继续采用本决策的组织规则。本次统一迁移执行全库验收；日常结构整理仍按增量范围执行。

人类站点的顶部八类分类冻结，层级由专题目录承载（分类 > 专题 > 文章，可多层嵌套）；一篇文章超过拆分阈值且自身即主题锚点时，裂变为同名小写英文目录（`index.md` 导读 + 成员文章 + `.nav.yml`），专题经合并只剩一篇时塌缩回单文件。概念的完整解释只在归属页出现一次，他处一句话提及 + 标准 Markdown 相对链接；反向链接由 `站点/工具/backlinks.py` 在构建期生成、不提交入库，CI 以 `zensical build --strict` 拦截断链。URL 随结构调整而变，不加重定向。

## Considered Options

- 顶栏随技术各开分类（如 Java 独立 tab）：拒绝——tab 无限膨胀；层级收进专题目录，顶栏保持八类。
- `[[wikilink]]` 语法与 MkDocs 反链插件（mkdocs-backlinks 等）：拒绝——zensical 只运行官方列名插件，未列名配置被静默忽略；采用标准相对链接 + 自研构建期脚本。
- 反链段落提交入库：拒绝——派生物不得污染事实源，正链是唯一事实源，反链每次构建重新派生。
- 全站一次性重排与查重：拒绝——增量收敛，整理触及的内容按归属页规则改写，未触及的留给后续整理。
- 断链静默告警：拒绝——`--strict` 让断链直接失败构建，防止链接腐化累积。
