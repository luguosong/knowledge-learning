# 章节按知识点组织

文章章节此前沿用提问原题作标题，目录呈现一串疑问句，与提问记录的溯源信息重复，阅读动线被问题语境打断。2026-11-02 起正文章节按知识点组织，提问记录退为纯溯源层。

## 已确认的决策

- 章节以知识点为单元：二级标题用名词短语命名，禁用疑问句；三级标题不设规范。
- 章节开头段直陈知识，不复述问题。问题语境只保存在提问记录。
- 同一知识点的段落合并到一个章节；章节按知识逻辑排序。
- 独立成章的知识点至少被一个问题引用。衔接与过渡段落不视为知识点。
- 问题与章节是多对多映射：多个问题可指向同一章节，一个问题的正文入口可列多个章节。
- 迁移只做章节级重组，不动文章文件边界；文章级合并、拆分、裂变与塌缩仍由结构整理流程处理。

## 迁移方案

- 一次性全站迁移含提问记录的主文章；导读页与补充页不改。
- 分片派改写代理重组单篇文章，另派独立验证代理对照 Git 迁移前版本逐段核对实质内容、来源与日期不丢失。
- 单篇验证失败即回滚该篇并继续其余篇目；部分迁移后全站仍自洽。
- 中文锚点随标题变化，站内正文入口同步更新；不保留旧章节 URL。

## 取舍

- 采用知识点命名，保留目录与正文的阅读连贯性。
- 不采用疑问句标题，放弃目录直接反映提问来路的能力；来路由提问记录承载。
- 不采用仅改标题不改开头的浅改写，避免问答腔残留导致二次返工。
- 采用改写与验证双代理，放弃单代理自报清单的低成本方案，以独立上下文兜住语义重组的内容丢失风险。
