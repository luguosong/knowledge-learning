# AutoCAD

## 综述

AutoCAD 自动化按运行中控制与无 AutoCAD 的文件处理区分；COM、AutoLISP 和 ezdxf 的适用产品、版本及格式不同。官方 Assistant/MCP 与社区项目的支持范围分别核实，社区维护状态不能替代本机兼容测试。基础学习先掌握样板、单位、精确绘图、注释出图和块，再选择行业或自动化方向。试用申请曾在中国大陆手机验证与中国区组件处受阻，不能据此推定当前服务状态。天正转 T3 仍产生 DWG；图层与可见图形的保留不等于专业参数和智能编辑能力完整保留。待解：官方 AutoCAD 专属 MCP 条目和配置，以及中文 Windows 下的社区方案兼容性。
