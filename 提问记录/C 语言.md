# C 语言

## 综述

C 开发环境需要编辑器、编译与链接工具、头文件及库、调试器和相应配置；集成开发环境（Integrated Development Environment，IDE）把这些工具组织到同一工作界面。Windows 上，Visual Studio 可通过“使用 C++ 的桌面开发”工作负载配置 Microsoft Visual C++（MSVC）与 Windows SDK，并按 C 语言编译 `.c` 文件；VS Code 的 C/C++ 扩展不附带编译器与调试器，可配合 MSYS2 分发的 GNU 编译器集合（GNU Compiler Collection，GCC）与 MinGW-w64 工具链；CLion 在 Windows 上附带 MinGW 工具链。选型应依据配置便利性、目标平台与工程习惯。x64 Windows 的 GCC 路线可选 MSYS2 UCRT64 环境，先用命令行验证编译，再连接编辑器的构建与调试功能；学习 C 应明确选择 `.c`、C 编译方式和语言标准。本次未确认用户的 Windows 版本、处理器架构及课程要求。
