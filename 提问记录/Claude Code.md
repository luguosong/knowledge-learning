# Claude Code

## 综述

学习主线是理论基础、单任务闭环、上下文与扩展、多任务编排、量化调优；先明确目标、范围和可运行验收，再按任务需要增加工具。subagent、会话 fork、角色配置、恢复实例和持久记忆分别理解；独立上下文不自动隔离文件，也不保证降低总用量。内置工具与随产品提供的技能可作为基线，没有通用必装扩展，也不能断言零扩展永远最佳。插件按重复缺口增加，描述、调用正文和自动流程各有成本，关注度不代表实测收益。Windows 与 WSL 均可集中运行 Claude Code；用户配置共用，项目规则、自动记忆和会话分别组织。两边同侧开发无通用性能排名；Linux 容器源码挂载、Rust 目标系统及命令沙箱支持决定取舍。局部命令倍率不能直接外推完整任务，效率取决于模型等待、本地操作和重试各占多少时间。PDF 翻译由智能体负责术语和修订，工具负责解析、排版和完整性，现有组合仍需实测。源码存档、第三方架构研究和独立实现必须区分，公开可见不代表获得开源许可。官方正文导出也不等于完整站点源码。地区政策锚定用户所在地而非 IP：大陆不在支持列表，经海外 VPS 接入仍是限制对象，VPS 仅降低检测概率，不构成合规路径。具体配置、数量和版本见对应问题；待解是在实际 Java／React 项目中验证委派、扩展和调优收益。
