# Git

## 综述

Git 是分布式版本控制系统；Bash 是命令解释器（Shell）。Git Bash 是 Git for Windows 提供的 Bash 命令行环境，让用户在 Windows 上按类 Unix 的方式执行 Git 与配套工具。理解 Git Bash 时，应区分负责版本管理的 Git、负责解释命令的 Bash，以及将这些工具带到 Windows 的软件包。在 Git 之上，GitHub 以分支与合并为基础提供 PR（Pull Request）合并提案机制：head 分支向 base 分支发起，经评审、Checks 与分支保护门禁后按 merge commit、squash 或 rebase 合并并删除分支；PR 是平台功能而非 Git 命令。
