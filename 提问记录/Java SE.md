# Java SE

## 综述

Java 标准版（Java Platform, Standard Edition，Java SE）的学习按工具执行、类型与对象、泛型和异常、核心类库、平台 API、并发、模块与打包递进。练习基线在 2026-10-15 从 JDK 21 修正为 JDK 25；语言、类库和运行时的增量按版本核对。dev.java 与官方规范承担现行依据，书籍按教学用途与覆盖版本组合，冻结在 JDK 8 的经典教程需要对照练习基线使用。类库按 Java SE 标准 API 与 JDK 专属 API 理解；模块组织包并声明依赖与导出，包名前缀不能单独判定 API 身份。桌面图形化主线为 AWT → Swing（均在 java.desktop）与 JavaFX（JDK 11 起由 OpenJFX 独立演进），第三方桌面工具包有 SWT 与 Compose Multiplatform，Apache Pivot 已退役。详细清单、书目和演变过程见独立问题。
