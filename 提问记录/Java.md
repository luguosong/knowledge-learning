# Java

## 综述

Java 专家路线从语言与标准库连接到算法、操作系统、并发、虚拟机、服务端工程和生产交付；先形成可测试的服务，再以故障诊断和设计取舍深化专项，知识清单不表示已经掌握。Java SE 的详细路线见 [[Java SE#综述]]。日志按事件、API、实现、输出及采集理解，区分应用、审计与 JVM 日志。JVM 先理解规范语义，再按版本研究实现并用可复现故障验收：跨平台靠各平台 JVM 执行同一字节码，HotSpot 在运行时探测热点并即时编译为本机代码，优化属实现而非规范。Java EE／Jakarta EE 是规范集合，Tomcat 实现其中的 Web 层子集；学习方向应按实际工程需求选择。待解：个人薄弱项和可持续学习时间。
