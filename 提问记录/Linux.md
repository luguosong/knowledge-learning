# Linux

## 综述

Linux 学习从命令行、文件权限、进程和启动进入存储、网络、安全、诊断与自动化，再选择专项；掌握程度以隔离环境中的部署、故障定位和恢复验证。LVM 跨盘合并容量不自动提供均匀写入或冗余，Docker 数据迁移需结合实际布局。入门采用一条学习主线并持续动手，时间估计不保证能力。WSLg 应用窗口与完整 Linux 桌面分开理解；本机 Xfce／xrdp 尚未完成安装登录验证。2026-10-27 的 WSL 配置与容器停止记录只代表当时状态：开发服务改为按需启动并保留数据，gradual 回收仍待 WSL 重启验证。WSL 软件包版本、WSL 1／2 架构、发行版版本分别理解；应用内存、缓存和宿主工作集分别诊断。Windows 与 WSL 文件互通是同一存储的跨系统访问（`\\wsl$` 路径与 `/mnt/c` 挂载，走 9P 协议），即写即见而非两份拷贝；项目文件应与工具同侧存放，Windows 侧修改不触发 Linux inotify 事件；Windows 下载文件经资源管理器拖入 `\\wsl$` 会把 MOTW 的 Zone.Identifier 流物化成独立文件（WSL #4609 bug），删除无害、加入 `.gitignore` 防入库。文本搜索工具 ripgrep 使用命令 `rg`；命令不可用、搜索无匹配和文件被过滤需分别判断。
