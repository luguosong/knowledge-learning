# MCP

## 综述

模型上下文协议（Model Context Protocol，MCP）的学习按架构接入、核心能力、消息与传输、交互、宿主与客户端、授权安全、部署及兼容推进。当前学习基线为 2026-07-28 规范：每请求在 _meta 中自带版本与客户端能力，不依赖此前建立的协议会话；_meta 承载通信元数据，arguments 承载工具业务输入；server/discover 是可选发现，不是握手。请求、响应、通知及内嵌输入分别定义字段，缓存结果须含 ttlMs 与 cacheScope；完整类型与示例见报文问题附录。宿主可以保存上下文，再把所需结果明确写入下一请求；无状态不表示应用不能保存数据。旧握手与会话机制属于兼容知识；MRTR、订阅和扩展语义见路线问题，扩展能力需双方显式支持。npx 是启动命令；本体是 JSON-RPC 2.0 消息语义，stdio 与 Streamable HTTP 只是可替换的传输绑定，stdio 不经 HTTP，OAuth 授权只面向 HTTP 传输；HTTP 可以运行在本机，stdio 不强制串行。宿主、SDK 与扩展支持按实际版本核实，通过服务器、客户端、多用户隔离及故障恢复练习验证。
