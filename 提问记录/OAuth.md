# OAuth

## 综述

学习主线是理解受限授权，再掌握授权码流程与 PKCE、令牌验证与生命周期、OIDC 身份层、安全机制、客户端架构和工程运维，最后按场景学习扩展。OAuth 2.0 是授权框架；OIDC 在其上提供身份认证；JWT 是数据格式，Bearer 是使用凭证的方式，二者不是同一维度。学习基线应结合 RFC 6749、RFC 6750、RFC 7636 与 RFC 9700，不能仅照搬早期四种授权模式。2026-09-22 核实：OAuth 2.1 仍为 draft-ietf-oauth-v2-1-16；浏览器应用指南已于 2026 年 8 月发布为 RFC 10017。路线按核心必修、工程必修、场景选修组织，以独立解释请求、安全失败用例和系统取舍为掌握标准。2026-10-12 核实：oauth.net 是 OAuth 社区维护的项目官网，非 IETF 站点；协议事实仍以 IETF RFC 为一手，oauth.net 用作社区第一方参考，定位为入门概览与规范索引，不作主干教程。系统教程补充 OAuth 2.0 Simplified（免费在线书）与 OAuth in Action（中文版《OAuth 2实战》，2017 年出版，安全结论需按 RFC 9700 与 RFC 10017 校正）。
