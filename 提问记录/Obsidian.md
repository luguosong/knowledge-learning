# Obsidian

## 综述

Obsidian Tasks 让任务保留在笔记中并跨库查询，通知需其他组件。Windows 与 iPhone 的私有查阅曾选择 Remotely Save 加 OneDrive；单向下载模式、远端删除与手机编辑的行为不同，iOS 后台和支持边界需核对。同步前备份并避免多个服务同时管理同一库。Obsidian Git 用于版本历史与备份，其提交、拉取和推送顺序不同于实时同步。Mermaid 美化插件按支持图型、主题覆盖、缩放和导出需求比较，安装前核实维护及兼容性。待解：任务插件的具体边界和个人工作流取舍。
