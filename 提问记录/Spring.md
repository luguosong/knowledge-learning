# Spring

## 综述

Spring 学习以 Spring Framework 为机制主线：先用原生 Java、Servlet 和 JDBC 认识对象装配、横切逻辑、请求分发与事务问题，再学习容器、代理、Web MVC、数据访问和测试；随后研究 Spring Boot 如何组织这些能力，并把 Spring Security 与生产诊断纳入一个可测试的单体服务。Spring Data、WebFlux、Cloud、Batch、Integration 等按业务需求分支深入。每一层都以“能使用、能沿调用链解释、能复现失效条件、能说明取舍”验收。此路线是基于官方资料的教学编排，并非 Spring 官方课程；版本行为以所用项目的 Framework、Boot、Cloud 对应文档为准。2026-10-15 核实：Spring Framework 7.0.x（JDK 17–25+）与 Spring Boot 4.1.x（Java 17–26）官方支持 JDK 25 且为推荐生产版本；Spring Cloud 现行列车 2025.1.x 对应 Boot 4.x。
