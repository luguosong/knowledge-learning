# VPS

## 综述

VPS 选型应分别考察虚拟化与存储架构、资源争用、服务承诺和用户到机房的网络；产品名称和 SLA 百分比不能直接代表实际稳定性。通用云主机、中国方向线路及家庭流量中转是不同需求，历史候选、价格、库存、条款和测试条件分别留在问题中，实际购买前重查。用户一项用途为苏州电信接入；家庭服务器问题仅确认苏州、自己和家人使用、允许客户端且只需中转，家宽运营商和上行尚未确认，不能沿用另一问题的网络条件。家庭互访可先测试点对点直连，再按端口映射或私有组网比较托管中转；这些是需求匹配建议，未经苏州线路实测。中继限速、共享带宽、流量配额和保证带宽必须区分；增加云端带宽不能消除家庭上行瓶颈。家宽动态公网 IP 可用 DDNS 让域名跟随 IP 变化，实现走 RFC 2136 或服务商 HTTP API；前提是有公网 IP，NAT 后无公网 IP 则 DDNS 无效，仍需中转或组网。
