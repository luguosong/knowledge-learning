# Windows

## 综述

Windows 家庭版与专业版按实际安全管理、远程接入、虚拟化和组织接入需求选择，具体功能及容量上限按版本核对。本机 RDP 客户端连接 WSL 内 xrdp 时，服务端在 Linux，无须据此升级 Windows 远程桌面主机能力。清理空间与减少后台负载分别诊断，清理文件数量不能证明提速。内存需区分工作集、提交量和缓存；清理后回涨不能单独证明泄漏。本机开发容器已按用户需求改为按需启动并正常停止，数据和配置备份保留；2026-10-27 尚未重启 WSL，gradual 回收配置仍待验证。
