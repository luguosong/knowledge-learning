# Zotero

## 综述

Zotero API 是程序访问文献库的接口。Zotero Web API v3 访问在线个人或群组库，公开库可匿名读取，私有库及写入须相应权限的 API 密钥；本地 API 由桌面客户端在 `localhost:23119/api/` 提供，读取本机库无需认证，但须在设置中启用，Zotero 10 及以上版本写入需用户授权的本地密钥。二者面向的程序运行位置与数据来源不同，选用时先确定程序运行地点。Translate for Zotero 插件的 DeepLX 是翻译服务选项，与 Zotero 自身 API 分属不同用途。
