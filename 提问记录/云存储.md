# 云存储

## 综述

阿里云对象存储（Object Storage Service，OSS）用于长期低频备份时，主要成本由平均实际占用容量决定。中国内地公共云按量计费中，归档、冷归档和深度冷归档的容量单价逐级降低，但最低存储期和恢复等待时间增加；外网流出、数据取回、请求另计。选型需同时看保留时长、恢复频率、恢复时限和备份版本累计容量；容量单价并非总成本。阿里云弹性计算服务（Elastic Compute Service，ECS）从 Windows 更换为 Linux 时，可先对系统盘和数据盘做快照，再从旧系统盘快照创建临时数据盘取回文件；旧快照不能直接回滚到新系统盘，应用和数据库仍需迁移。跨系统原地更换仅支持中国内地地域，NTFS 数据盘需额外方式读取。
