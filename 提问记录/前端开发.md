# 前端开发

## 综述

网页编辑器先按 Markdown 往返结果、富文本交互和维护状态选型，再用实际文档验证；历史候选包括 Vditor、Milkdown Crepe，TOAST UI Editor 的归档状态见原问题。后台设计风格按信息密度与操作任务选择，合集示例仅作设计参考。三维地球按 GIS 场景、地图优先或数据展示选择 CesiumJS、MapLibre GL JS、globe.gl 等候选；开放数据格式有助于交换，渲染 API 仍各自独立，许可需按版本核对。地图服务端另行选型：空间数据发布与瓦片服务见 GIS 领域。
