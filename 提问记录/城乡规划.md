# 城乡规划

## 综述

城乡规划的学习主线是“认知改革脉络 → 学科基础（原理、历史、支撑学科）→ 法规与规划管理 → 编制体系与技术标准 → 详细规划与制图 → 专项深化 → 执业实务”。2019 年《中共中央 国务院关于建立国土空间规划体系并监督实施的若干意见》（中发〔2019〕18号）将主体功能区规划、土地利用规划、城乡规划融合为国土空间规划，实现“多规合一”，形成“五级三类四体系”；学科与教材仍以城乡规划为名（一级学科 0833、《城市规划原理》），学习须以新体系为主线、旧原理为根基。红线出图属于详细规划与报建制图环节，涉及用地红线、道路红线与建筑退线。待解：学习目标（执业考试、规划编制或规划信息化）未确认；地方退让标准、《城市用地分类与规划建设用地标准》（GB 50137-2011）现行状态未核实。
