# 容器编排

## 综述

K8s 是声明式 API + 控制循环的容器管理平台（Google 2014 年开源，源自内部 Borg 经验，CNCF 托管）：声明期望状态，控制器持续把集群现实收敛到期望，据此自动完成部署、扩缩容、自愈与流量分发。与 Docker 曾绑定（kubelet 内置 dockershim）、后经 CRI 标准解耦（1.24 移除 shim）；今日分工——Docker 造 OCI 镜像，集群用 containerd 跑镜像。在 Java 服务端学习路线中，本领域位于应用构建、单机交付之后；学习重点是镜像、配置、资源限制、探针、优雅停机、发布与回滚，以及应用和平台的责任边界。Docker 本机存储容量取决于其存储目录所在的文件系统，跨盘合并容量应在主机存储层完成；Docker Engine 29.0 起全新安装默认使用 containerd 镜像存储，镜像和容器快照默认位于 /var/lib/containerd，其位置不受 Docker data-root 控制。
