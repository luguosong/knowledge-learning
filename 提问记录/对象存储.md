# 对象存储

## 综述

判断对象存储软件是否继续运营，需区分公司业务、产品发布与开源仓库维护。已有核实表明 MinIO 仍有 AIStor 订阅、支持与发布活动，但原开源 minio/minio 仓库于 2026-04-25 归档；AIStor Free 需申领许可证并限定单个计算资源，公开产品活动不能证明公司内部财务状况。2026-10-13 深化到项目文件管理：Silo 是保留 MinIO 兼容面的直接分支，当前已发布 Server 为 20260903，2026-09-16 是主分支存在未发布改动的说明日期；新建文件存储可评估 SeaweedFS、RustFS、VersityGW 或 Garage，选择取决于部署规模、底层存储、权限与版本需求。SeaweedFS 提供对象与文件接口，RustFS 已发布 1.0.1 但兼容范围须按发布标签核实，VersityGW 适合把已有目录暴露为 S3，Garage 适合轻量异地副本且缺少 S3 版本、策略、ACL 与对象锁。Cloudreve 是完整文件管理系统，X File Storage 是 Java 存储适配库；二者与对象存储服务处于不同层。S3 API 兼容不保证管理接口、权限语义或磁盘格式兼容；本次选型是有条件的架构判断，未做部署或性能实测，最终仍需核实项目规模与是否需要用户文件管理界面。
