# 平面设计

## 综述

智能体（AI Agent）驱动平面设计的主线是需求与品牌约束、素材生成、可编辑排版、渲染检查、局部修订与交付。用户的实际目标已由参考图限定为软件产品功能介绍页：真实界面截图、技术示意图、密集中文与统一品牌版式；建议优先采用网页加 Playwright 交付图片和 PDF，需要可在演示软件中改字、换图时采用 PptxGenJS，而不是以整页生图作为主流程。多页宣传册需要固定模板、分页与逐页检查；正式印刷还需要按印厂规格设置色彩、字体、出血及文件规范。Penpot 官方 MCP 与 OpenPencil 提供画布自动化，Poster Maker 展示代码排版闭环，Fabric.js 与 Konva.js 可用于自建编辑器；ComfyUI 与 Diffusers 负责素材生成，不替代排版。Typst 适合代码化多页排版；WeasyPrint 70.0 已列 PDF/X 导出，官方仍要求核查结果合规；Scribus 适合脚本填充与人工复查相结合的印刷工作。Paper2Poster 与 PosterGen 是学术海报研究实现，不能直接视为商业宣传册的成熟成品。项目代码、模型和字体素材的许可应分别核实。本次仅核实一手文档与仓库，未安装、未做端到端或质量排名实测。
