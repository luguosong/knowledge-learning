# 数据结构与算法

## 综述

数据结构与算法的学习主线是“编程与离散数学 → 复杂度和正确性 → 线性结构与基本算法 → 树、图及算法设计 → 进阶专题 → 工程或理论专项”。已有 Java 路线列过基础结构、常用算法和部分工程结构；数学路线提供证明、组合、图论、数论与复杂性入口；密码学路线涉及随机算法、模运算和计算困难性。本领域将这些概览展开为分阶段清单。“已有记录”仅表示此前提及，不表示已经学习或掌握；尚无逐项能力验收结果。核心主干应同时训练建模、实现、证明、复杂度分析与选型；进阶内容按任务选择，数学先修随主题补足，不要求先完成全部数学路线。
