# 文本编辑器

## 综述

桌面代码编辑器选型：GitHub 组织 storytold（ArtCraft）没有 Notepad++ 式代码编辑器。可直接采用的开源选择按需求分组——Notepad++ 同款体验：Notepad++（Windows 本尊）、Notepad Next（跨平台复刻）；轻量跨平台：Geany、CudaText、Kate（均覆盖 Win/Linux/macOS）；现代 Rust 系：Zed、Lapce；IDE 级：VSCodium（VS Code 去遥测构建）；终端模态：Neovim、Helix。上述 10 个项目在 2026-10-12 核实时全部活跃维护。
