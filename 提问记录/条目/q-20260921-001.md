# 2026-09-21 · 用户身份认证技术的演化过程

- **问**：用户身份认证技术是怎么一步步演化过来的？
- **答**：主线是"秘密不断向更安全的位置迁移"：明文密码（1961 CTSS）→ 哈希+盐（1979 Morris & Thompson）→ 票据/挑战响应，密码不上网络（1988 Kerberos、1998 S/KEY RFC 2289）→ 一次性口令双因素（2005 HOTP RFC 4226、2011 TOTP RFC 6238）→ 联邦单点登录（2005 SAML 2.0、2014 OpenID Connect；OAuth 2.0 是 OIDC 的授权基础）→ 公钥抗钓鱼无密码（2012 FIDO 联盟、2014 U2F、2019 WebAuthn/FIDO2、2022 Passkeys）。每一代都修复上一代"共享秘密"的暴露面：WebAuthn 起服务器只存公钥、私钥永不出设备、签名绑定域名，钓鱼与拖库同时失效。
- **修正**：原答把“2012 OAuth 2.0 RFC 6749”直接列入用户认证演化，此归类**已被 2026-09-22 修正**：OAuth 2.0 是授权框架，OIDC 在其上定义身份层。
