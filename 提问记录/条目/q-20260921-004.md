# 2026-09-21 · k8s 和 Docker 的关系（承接上条）

- **问**：k8s 和 docker 之间是什么关系
- **答**：曾绑定、后解耦。早期 k8s 靠 kubelet 内置的 dockershim 直接调 Docker 跑容器；2016 年 k8s 1.5 引入 CRI 标准接口，2017 年 Docker 把核心运行时 containerd 捐给 CNCF；2020 年（1.20）弃用、2022 年（1.24）移除 dockershim，此后集群直接用 containerd/CRI-O，与 Docker 无直接依赖。但 Docker 构建的镜像本就是 OCI 镜像，集群照常运行——今天的关系是"开发用 Docker 造镜像，集群用 containerd 跑镜像"。
- **信源**：[一手] https://kubernetes.io/blog/2020/12/02/dont-panic-kubernetes-and-docker/ · [一手] https://kubernetes.io/blog/2020/12/02/dockershim-faq/ · [一手] https://www.cncf.io/blog/2017/03/29/containerd-joins-the-cloud-native-computing-foundation/
