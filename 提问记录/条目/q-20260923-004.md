# 2026-09-23 · Spring 框架的完整学习路径与知识地图

- **答**：以 Spring Framework 的容器、代理、Web 与事务为核心，按问题动机 → 最小实现 → 框架抽象 → 源码调用链 → 故障实验的顺序学习；Spring Boot、Security 和测试进入主线，其他 Spring 项目按场景扩展。“全部”指主要机制及现代服务端工程知识地图，不指每个项目、类和注解的穷举。
