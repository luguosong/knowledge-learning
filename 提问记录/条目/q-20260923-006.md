# 2026-09-23 · Grok Bot 是什么：常驻智能体队友产品

- **问**：Grok bot 是什么？
- **答**：Grok Bot 是 SpaceXAI（原 xAI，2026-02-02 并入 SpaceX）于 2026-08-11 发布的常驻智能体产品：用户创建多名有名字、有职责的“AI 队友”，它们 7×24 在线，共享一台按用户隔离的持久云端计算机，能登录用户的工具并以图形界面方式操作，带回完成的工作。它与 Grok 聊天机器人（2023-11-03 发布）和终端编程智能体 Grok Build 是三个产品。
- **信源**：[一手] [Grok Bot 产品页](https://x.ai/bot)、[SpaceXAI 新闻列表](https://x.ai/news)、[Grok API 文档](https://docs.x.ai)；[二手] The Verge 2026-08-12 报道（发布事件旁证）

### 关键事实（2026-09-23 核实）

- 形态：桌面客户端（macOS、Windows）与 iOS；以对话方式给 Bot 派活，可多 Bot 并行，笔记本关机后云端继续执行。
- 隔离粒度：同一用户的所有 Bot 共享一台持久云端计算机（文件、浏览器、登录态按用户隔离，不按 Bot 隔离）。
- 教学机制：Bot 可观看用户演示一遍工作流并存为例行任务，此后自主执行。
- 协作与记忆：多个 Bot 可进入同一线程互相传递工作；Bot 保留上下文并可互相学习。
- 安全：敏感操作需经 Auto Review；传输与静态加密；可退出训练；企业版支持 DLP、证书与代理。
- 订阅：Cursor Pro／Pro+／Ultra、SuperGrok／SuperGrok Plus／Heavy 及 Teams、Enterprise 计划包含，额外用量按 token 成本计费。
- 演进时间线：2026-08-11 发布；08-26 纳入 SuperGrok 与 Cursor 订阅；08-29 与 X 集成；09-03 企业版与《Designing Grok Bot for a world of persistent agents》一文；09-22 官方发布用 Grok Bot 扩展客服的用例。
- 设计原则（官方设计文章）：聊天历史变成 Bot 名册、Bot 有在线状态、有自己的计算机、工作可不经提示开始。
- 定位参照：常被与开源个人智能体 OpenClaw 对比（[二手] Lenny's Newsletter 2026-09-02）。
