# 2026-09-23 · RDP 是什么以及与住宅 IP 有何关系

- **问**：什么是rdp
- **答**：远程桌面协议（Remote Desktop Protocol，RDP）通过网络把远程 Windows 电脑的画面传给本地设备，并把本地键盘和鼠标操作传回远程电脑。RDP 是连接协议；“RDP 电脑”是商家的产品叫法，其公网出口 IP 由远程电脑的网络决定，不能从 RDP 名称推断为住宅 IP。
