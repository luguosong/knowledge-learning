# 2026-09-26 · Obsidian Git 插件设置与自动同步策略

- **问**：根据八张 Obsidian Git 设置截图，详细讲解如何配置。
- **答**：先确认 Git 仓库、远端、Windows Git Credential Manager 与提交作者；再选择自动策略。分离定时器时，自动提交、推送、拉取独立，截图中的 60／68／75 分钟不保证先拉取再推送；多设备以 Git 同步时，宜关闭分离定时器，使用定期“提交并同步”（提交→拉取→推送），保留错误通知，冲突策略选 Git 默认。若 OneDrive + Remotely Save 已负责跨设备同步，可只在桌面端用 Git 保存历史与备份，避免两个工具同时管理同一文件的双向合并。
