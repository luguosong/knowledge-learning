# 2026-09-26 · 目前免费的翻译 API 接入方案

- **问**：目前免费的翻译api接入方案；追问：那deeplx又是什么；有没有办法我服务端自己部署一套免费的翻译引擎
- **答**：国内优先核对百度翻译标准版或个人认证高级版；国际服务可选 Azure Translator F0 或 Google Cloud Translation NMT 的月度免费额度。DeepL API Developer 为累计 100 万字符试用。真正自托管翻译可优先试无需显卡、提供 REST 接口且被 Translate for Zotero 支持的 MTranServer；LibreTranslate 是另一套基于 Argos Translate 的本地引擎。两者免第三方按字符收费，但服务器、下载模型与维护仍有成本。若质量不足，可评估资源需求更高的 Hy-MT2-1.8B。腾讯云旧机器翻译免费包 2026-10-01 起停止续发。DeepLX 已更名 DLX，是依赖 DeepL 非公开接口的非官方服务，不提供 DeepL 官方 API 额度；DeepL 免费服务条款禁止未经书面许可使用内部 API。Zotero 翻译插件中的 DeepLX 直接请求非公开接口，DeepLX(API) 使用自定义地址，与 Zotero API 无关。
