# 2026-09-29 · Windows Server 更换 Linux 时用云盘快照恢复数据

- **问**：我现在使用的是win server,希望重装成linux。我是否可以利用阿里云的云盘快照功能。先备份硬盘数据，重装成liunx后再进行数据恢复
- **答**：若为阿里云 ECS 且位于中国内地地域，可对旧系统盘和数据盘创建快照后更换为 Linux。更换会释放旧系统盘；旧系统盘快照只能创建临时数据盘以提取文件，不能回滚到新 Linux 系统盘。Windows 应用需要重装或替换，数据库需保证一致性并迁移；NTFS 数据盘需要额外工具读取。中国内地以外地域不能在同一实例上跨类型更换。
