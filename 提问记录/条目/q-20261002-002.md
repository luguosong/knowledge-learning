# 2026-10-02 · 系统盘与数据盘合并后供 Docker 使用的方式与取舍

- **问**：linux中一块系统盘和一块数据盘。能不能将它们合成一个整体，我装docker容器时，自然的同时用到这两块盘
- **答**：可以用逻辑卷管理器（Logical Volume Manager，LVM）将两盘上纳入管理的空间组成跨盘线性逻辑卷，在其文件系统上存放 Docker 数据，以使用分配给该卷的合并容量；仅创建卷组或挂载数据盘不会自动合并 Docker 可用容量。线性卷不保证均匀或并行读写，也无冗余，任一盘故障可能使跨盘文件系统不可用；已有非 LVM 系统分区需规划迁移，若只想减轻系统盘占用，可以保持两盘独立并迁移 Docker 存储，但使用 containerd 镜像存储时须分别考虑 Docker 的 data-root 与 containerd 的 root。
