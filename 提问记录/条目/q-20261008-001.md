# 2026-10-08 · 截图中的翻译模型哪款英译中表现最好

- **问**：BabelFast (Beta)、DeepSeek-V4.1-F…、Qwen 3.5 Plus、Gemini 3 Flash、GPT-6 Luna、GLM-4.7、DeepL Pro、Claude Haiku 4.5、PLaMo 3.0 Prime、Grok 4.3 中，哪款英文翻译成中文表现最好？追问：DeepL Pro 好像是 2024 年的？是不是太老了？
- **答**：目前核实的资料不足以确定截图服务的英译中第一名，2024 年主要对比 ChatGPT-4 等旧型号的厂商盲测也不足以支持当前优先推荐 DeepL Pro。DeepL Pro 是订阅服务名，不能用它确定底层模型的年份；官方 API 文档说明 DeepL 持续部署新模型，但插件实际调用的模型仍未核实，应比较同一段原文的准确性、漏译与术语一致性。
- **修正记录**：旧结论“如果需要立即选一个默认引擎，建议先试 DeepL Pro，这是基于其官方中英专家盲测的选型建议”已被 2026-10-08 修正：该发布页标注 2024-07-16，竞争型号过旧，不能据此支持当前推荐优先级。
- **信源**：[一手] [DeepL：新一代语言模型与专家盲测](https://www.deepl.com/en/blog/next-gen-language-model)（页面标注 2024-07-16；包括英语与简体中文；厂商自报，竞争型号过旧）；[一手] [DeepL 发布商说明](https://www.deepl.com/zh/publisher)（DeepL Pro 于 2018 年 3 月推出）；[一手] [DeepL：Understanding Model Types](https://developers.deepl.com/docs/translate/understanding-model-types)（持续部署新模型；模型选择基于请求与目标）；[一手] [DeepL API 更新日志](https://developers.deepl.com/docs/resources/roadmap-and-release-notes)（2024 年第 4 季度增加 next-gen 模型选择参数；2025 年至 2026 年仍有更新，功能更新本身不证明当前英译中排名）；[一手] [HardMTBench 原始论文](https://arxiv.org/html/2605.28315v1)（中英双向专业领域评测；型号不能直接等同于截图服务）；[一手] [沉浸式翻译更新日志](https://immersivetranslate.com/zh-Hans/docs/CHANGELOG/)（2026-06-22 将 BabelFast 定位为实验性快速翻译服务）。
