# 2026-10-10 · VPS 是什么

- **问**：vps 是什么
- **答**：VPS（Virtual Private Server，虚拟专用服务器）是把一台物理服务器经虚拟机监控器（Hypervisor）切分成多台虚拟机后出租的形态：每台份额专用、租户隔离，有独立操作系统与 root 权限，可独立重启。定位介于共享主机与独立服务器之间；阿里云 ECS 等云服务器是其云时代形态。
