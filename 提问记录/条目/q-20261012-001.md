# 2026-10-12 · in Action 系列中服务器认证与鉴权的成书盘点

- **问**：Manning "in Action" 系列有没有通用服务器认证和鉴权的书，不局限于 OAuth？
- **答**：有，但按视角分册，无一本总纲：API Security in Action 覆盖通用服务器认证与授权模式（认证、授权、审计、限流、加密，Java 示例）；Spring Security in Action 第二版（2024-04，Spring Boot 3、OAuth2/OIDC 更新）覆盖 Java 工程实现；OAuth 2 in Action 深挖协议。Microservice Security in Action（2021）仅二手确认存在，Manning 页面已下架。通用 IAM 服务器 Keycloak 在 in Action 系列内无书，实际成书是 Packt 的 Keycloak IAM 书。API Security in Action 与 OAuth 2 in Action 均出版早于 RFC 9700，安全结论需按安全 BCP 校正。
- **信源**：[一手] [Spring Security in Action](https://www.manning.com/books/spring-security-in-action)（Manning，2020-10）；[一手] [Spring Security in Action, Second Edition](https://www.manning.com/books/spring-security-in-action-second-edition)（Manning，2024-04，Spring Boot 3）；[一手] [API Security in Action](https://www.manning.com/books/api-security-in-action)（Manning，2020-11，Neil Madden）；[一手] [OAuth 2 in Action](https://www.manning.com/books/oauth-2-in-action)（Manning，2017-03）；[二手] Keycloak – Identity and Access Management for Modern Applications（Packt，Thorgersen 与 Pedro Igor Silva，AbeBooks 条目）；[二手] Microservice Security in Action（Manning 2021，[Medium 引用](https://medium.com/@moghiny/everything-you-need-to-know-about-oauth-2-0-ceab235ff020)；一手页面 404，未核实）。
