# 2026-10-12 · oauth.net 是社区官网而非 IETF 官方站点

- **问**：https://oauth.net/ 属于第三方还是官方网站？
- **答**：它是 OAuth 社区（协议项目本身）的官网，不是第三方教程站；但 OAuth 是开放标准，规范权威在 IETF OAuth 工作组发布的 RFC。oauth.net 由社区志愿者编辑维护，不是 IETF 站点。引用协议事实以 RFC 为一手，oauth.net 作社区第一方参考。
- **信源**：[一手] [oauth.net 首页](https://oauth.net/)（社区站点，页面经 GitHub 编辑，源码指向 aaronpk/oauth.net 仓库）；[一手] [oauth.net 社区页](https://oauth.net/community/)（自述社区目标，并写明 IETF 邮件列表负责标准化工作）；[一手] [IETF OAuth WG](https://datatracker.ietf.org/wg/oauth/about/)（官方渠道为 datatracker、wiki、Zulip 与邮件列表，未链接 oauth.net）。
- **更新**：2026-10-12。追问"用 oauth.net 学 OAuth 2 是否好选择、有无更好资源"：oauth.net/2/ 实测为概念页＋RFC 链接的导览索引（核心概念、grant types、令牌管理、发现注册、PAR/DPoP/mTLS、OAuth 2.1），无分步教学；适合起步概览、查扩展对应规范、跟踪 2.1。系统教程用 [OAuth 2.0 Simplified](https://www.oauth.com/)（免费在线书，Aaron Parecki 著）与 [OAuth 2 in Action](https://www.manning.com/books/oauth-2-in-action)（Manning 2017-03，Justin Richer 与 Antonio Sanso 著；中文版《OAuth 2实战》，二手寻源：豆瓣）。该书出版早于 RFC 9700 与 RFC 10017，安全结论需按安全 BCP 校正。主干仍是 [[条目/q-20260922-006|2026-09-22 · 掌握 OAuth 2.0 的学习路线与完整知识地图]] 的 RFC 基线。
