# 2026-10-12 · 支持代码高亮的开源文本编辑器项目推荐

- **问**：推荐一些支持代码高亮的编辑器项目（Notepad++ 那种）。
- **答**：按需求分组——Notepad++ 同款：Notepad++（Windows）、Notepad Next（跨平台复刻，Win/Linux/macOS）；轻量跨平台：Geany、CudaText、Kate（均 Win/Linux/macOS）；现代 Rust 系（GPU 渲染、启动快）：Zed、Lapce（均已官方支持 Win/Linux/macOS）；IDE 级：VSCodium（VS Code 去遥测自由构建）；终端模态：Neovim、Helix。10 个项目在 2026-09-29 至 2026-10-12 间均有代码推送，全部活跃。星标数（2026-10-12）：Neovim 103k、Zed 91.6k、Helix 46.6k、Lapce 38.9k、VSCodium 33.6k、Notepad++ 29.5k、Notepad Next 14.7k、Geany 3.7k、CudaText 3.2k、Kate 1.1k（GitHub 镜像）。
