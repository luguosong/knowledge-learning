# 2026-10-13 · AutoCAD 自动化操作 MCP 的官方与社区现状

- **问**：AutoCAD 有没有相关自动化操作的 MCP。
- **答**：有，官方与社区两条线。官方：AutoCAD 2027 起内置 Autodesk Assistant 并开始使用 MCP，官方 FAQ（2026-09 修订）确认部分 Autodesk MCP 服务器可作为独立能力经 Design and Make Marketplace 获取。社区：多个开源 MCP 项目，活体控制走 COM（完整版）或 AutoLISP 注入（LT 2024+），无 AutoCAD 时用 ezdxf 直接读写 DXF。
