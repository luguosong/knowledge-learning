# 2026-10-14 · 产品化服务/咨询去哪里找客户

- **问**：以产品化服务（Productized Service）/咨询为例，客户从哪里来？
- **答**：四层渠道按信任浓度与可收单价排序：①存量人脉与转介绍——质量最高、成本最低，自由职业调查中推荐为第一客户来源（小样本，二手）；②客户所在的社区与内容——去客户聚集地（行业群、知乎/小红书客户问题），不去程序员社区；③接单平台起步——Upwork（自由职业者服务费 0–15% 变动，自带客户 0%，官方）、Fiverr（抽成 20%，二手；gig 即产品化服务原生形态）、国内程序员客栈/电鸭社区/码市/解放号（猪八戒比价严重，二手）；④冷邮件/冷私信 + 单页案例站。推荐顺序：人脉冷启动 → 平台/社区攒案例与评价 → 内容长尾询盘 → 转介绍飞轮；平台是起步与攒信用手段，非长期主线。
