# 2026-10-15 · JDK 25 支持现状（Spring 各线）

- **问**：Spring、Spring 微服务（Spring Cloud）现在都支持 JDK 25 了吗？
- **答**：支持，且 JDK 25 是官方推荐的生产版本。Spring Framework 7.0.x 为当前生产线（2025-11 起），JDK 区间 17–25+，团队生产推荐 JDK 25 或更高；Spring Boot 4.1.x（现行）与 4.0.x 均要求 Java 17 起、兼容至 Java 26；Spring Cloud 现行列车 2025.1.x（Oakwood）对应 Boot 4.0.x／4.1.x。旧线：Framework 6.2.x 同样支持 JDK 17–25 但开源支持已于 2026-06 结束；Boot 3.5 对应的列车 2025.0.x 已 EOL——新项目直接 JDK 25 + Boot 4.x + Cloud 2025.1。
- **信源**：[一手] [Spring Framework Versions 官方 Wiki（各版本 JDK 区间与支持期限）](https://github.com/spring-projects/spring-framework/wiki/Spring-Framework-Versions)；[Spring Boot 4.1 系统要求（Java 17–26）](https://docs.spring.io/spring-boot/system-requirements.html)；[Spring Boot 4.0 系统要求（Java 17–26）](https://docs.spring.io/spring-boot/4.0/system-requirements.html)；[Spring Cloud 项目页（发布列车与 Boot 兼容表）](https://spring.io/projects/spring-cloud)。核实日期：2026-10-15。
- **关联**：[[条目/q-20260923-003|2026-09-23 · Java SE 的学习路线与完整知识点]]

### 各线支持对照

| 组件 | 现行版本 | JDK 支持 | 备注 |
| --- | --- | --- | --- |
| Spring Framework | 7.0.x（2025-11 起生产线；7.1 预计 2026-11） | 17–25+，生产推荐 25+ | Jakarta EE 11 基线（Servlet 6.1、JPA 3.2） |
| Spring Framework | 6.2.x | 17–25 | 开源支持 2026-06 结束，商业支持延续 |
| Spring Framework | 5.3.x | 8–21 | 开源支持 2024-08 结束，存量系统 |
| Spring Boot | 4.1.x（现行；4.0.x 同为 17–26） | 17–26 | 需 Framework 7.0.9+；Tomcat 11（Servlet 6.1）、Jetty 12.1 |
| Spring Cloud | 2025.1.x（Oakwood） | 随 Boot 4.0.x／4.1.x | 2025.0.x（Northfields，Boot 3.5）已 EOL |

### 要点辨析

- **"支持 25"不等于"要求 25"**：各线基线（最低要求）均为 Java 17；25 是受支持且被推荐的运行版本。Spring 自身按 17 语法编译，在 25 上运行是官方支持路径。
- **跟进节奏**：Boot 4.x 上界到 Java 26（非 LTS 过渡版），说明 Spring 随 JDK 六个月节奏滚动适配。
- **微服务起步组合（2026-10）**：JDK 25 + Boot 4.1 + Cloud 2025.1.x BOM；Boot 3.5 + Cloud 2025.0 的组合已停止支持，不再作为新项目起点。
