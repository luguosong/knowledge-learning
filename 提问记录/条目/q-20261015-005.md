# 2026-10-15 · PDF 文档翻译的成熟方案与库服务选型

- **问**：目前 PDF 文档翻译最成熟、最稳定、效果最好的方案，以及相关库和服务；追问澄清：不是传统方式，而是 AI agent 方案；进一步限定：基于 Claude Code 等智能体与工具搭建自己的翻译流程。
- **答**：用户最终限定为基于 Claude Code 等智能体与工具自建 PDF 翻译流程；可先评估 Claude Code 加 translate-book Skill，长期程序化批处理可用官方 Claude Agent SDK，译文由 agent 生成、审校和修订，解析与排版由工具完成。translate-book 具有分块、术语反馈、清单校验与断点续跑，但会重新排版；需要保留原版式时可把 PDFMathTranslate-next/BabelDOC 接为排版工具并开发翻译适配层，此为工程组合建议，尚未整体实测，通用最佳或最稳定结论未核实。
- **原答（传统文档翻译范围，已被 2026-10-15 的范围澄清修正）**：普通 PDF 可先试 DeepL，英文学术双语与保留版式可评估 PDFMathTranslate-next/BabelDOC，企业批处理可比较 Azure Document Translation 与 Google Cloud Translation Advanced；这些是按公开功能给出的选型建议，本次未核实通用第一名。开源方案必须分清整份翻译、OCR/解析与排版组件，尤其 BabelDOC 直接接口被官方标为内部接口，官方推荐经 pdf2zh_next 集成；扫描件、混合 PDF、公式与复杂表格仍需抽检。
- **核实细节**：沉浸式翻译 PDF Pro 支持扫描件、公式识别和逐段双语，但多栏会重排为单栏。DeepL PDF API 每文件至少计 50,000 字符。Azure 2026-03-01 GA 的 Document Intelligence PDF 增强仅适用于批量接口，数学公式上下标仍有已知格式问题；FAQ 仍保留混合 PDF 只翻译数字文本的限制，未明确新版批量接口是否已移除。Google 明确不翻译混合 PDF 中的扫描内容，Advanced 的 SLA 月可用性目标为至少 99.9%，不代表译文质量。原 PDFMathTranslate README 将原版定位为 stable release，将 next 定位为开发分支；next 自称 BabelDOC 官方参考实现，两者描述角度不同，不能推出 next 更稳定。PaddleOCR 的 PP-DocTranslation 已提供 PP-StructureV3 与大模型结合的翻译流程，可输出 Markdown，当前版本另支持 DOCX；Docling、MinerU 是解析组件；PyMuPDF 提供提取、渲染与写入能力，不能单独完成整份文档翻译。

- **Agent 范围核实**：Smartcat Chief of Staff 官方文档列出文档上传/导出、译段读写、术语库、翻译记忆和质量工具，并协调 Translator、Reviewer 等 coworker；审校能力受套餐限制。其 AI PDF 路线仅支持文字型 PDF，扫描件须另用 PdfImageOnly 路线并手工建项目；不能把不同路线能力拼成一个已验证的全自动流程。DeepTrans Studio 支持 PDF、术语、翻译记忆、多智能体和质量评价；2026-07-25 的 0.6.0 才开始正式可追溯版本管理，句法修订需要人工确认，不应据此宣称无人值守生产成熟。translate-book 实际由宿主 agent 调度分块子智能体，具有术语反馈、清单校验、断点续跑和选择性重译；经过 Markdown、Pandoc、Calibre 重新排版，不能承诺 PDF 原版式不变，其路线图仍保留整书实测质量验证。Andrew Ng 项目为初译、反思、改译三阶段演示，作者明确说明未成熟，评测有时优于、有时差于商业方案。

- **最终范围补充**：Claude Agent SDK 提供与 Claude Code 相同的 agent 循环、工具、上下文管理、会话、子智能体、hooks 和 MCP 接入，支持 Python 与 TypeScript；Python 包为 claude-agent-sdk。个人交互式任务可使用 Claude Code，嵌入自有进程的批量任务可使用 Agent SDK。translate-book 是可运行于 Claude Code 等宿主的第三方 Skill，翻译在宿主 agent 中完成；它经 Markdown、Pandoc、Calibre 重新生成结果，公式和多栏密集 PDF 应先用布局感知解析器提取。Claude 主控、术语表、分块翻译、审校返工、确定性完整性检查、排版和渲染验收为建议流程，不是已核实的单个成熟成品。商业翻译服务不再作为本次最终推荐方向。
