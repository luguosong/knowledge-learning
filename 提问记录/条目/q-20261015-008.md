# 2026-10-15 · Chrome 网页护眼插件的选择

- **问**：chrome 网页护眼插件
- **答**：若要把白底网页调暗，优先试 Dark Reader；若想设置米色、浅绿色等背景，可选支持自定义背景与文字颜色的 Midnight Lizard。先只启用一个同类扩展；网站显示异常时可对该网站停用。
- **信源**：[一手] [Dark Reader 官方 Chrome 商店页](https://chromewebstore.google.com/detail/dark-reader/eimadpbcbfnmbkopoojfekhnkhdbieeh)；[一手] [Dark Reader 官方说明](https://darkreader.org/help/zh-CN/)；[一手] [Midnight Lizard 官方 Chrome 商店页](https://chromewebstore.google.com/detail/midnight-lizard/pbnndmlekkboofhnbonilimejonapojg)
