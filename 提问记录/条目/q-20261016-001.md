# 2026-10-16 · 默认、AV1、HEVC 与 AVC 视频播放策略有什么区别

- **问**：播放器中的“默认、AV1、HEVC、AVC”几种视频播放策略有什么区别？
- **答**：AV1、HEVC／H.265 与 AVC／H.264 是不同的视频编码，主要取舍是压缩效率、兼容性和解码功耗；较新的编码通常能用较少数据维持相近画质，但画质和流畅度不能仅由编码名称判断。建议先用默认；如果手动选择，则结合硬件解码支持与实际播放表现决定，具体平台的默认规则尚未核实。
