# 2026-10-18 · Windows 上 C 语言开发环境、工具链与 IDE 的选择和搭建

- **问**：windows系统中C语言环境的搭建，开发环境、ide等。
- **答**：若希望减少配置，可选 Visual Studio 并安装“使用 C++ 的桌面开发”工作负载；若希望直接掌握编译命令，可选 VS Code 加 MSYS2 的 GCC/MinGW-w64 工具链；CLion 在 Windows 上附带 MinGW 工具链。x64 Windows 的 GCC 路线可选 UCRT64 环境，将其 `bin` 目录加入用户 `Path`，用 `.c` 文件与 `gcc -std=c17 -Wall -Wextra -g main.c -o main.exe` 验证构建；C17 是本次示例基线，使用 `g++` 默认会将 `.c` 文件按 C++ 处理。
