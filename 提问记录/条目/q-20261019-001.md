# 2026-10-19 · ZCode 桌面版基于什么技术打包 JS

- **问**：GitHub 仓库 zai-org/ZCode 基于什么技术将 JS 做成桌面端？
- **答**：桌面版基于 Electron 41，以 electron-builder 打包 mac/win/linux 安装包；这是“JS 与 Chromium+Node.js 运行时一起分发”，不是编译为原生代码。仓库内真正的编译环节：主进程 TypeScript 经 tsup、渲染层 React 经 Vite 构建为 JS，node-pty 等原生模块按平台重编译，桌面内置 Agent 可编译为 V8 字节码；CLI 版另有可选的 Node.js SEA（Single Executable Application，单一可执行应用）打包。
