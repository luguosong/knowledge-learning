# 2026-10-22 · 从 awesome-design-md 合集为后台管理项目选设计风格

- **问**：https://github.com/voltagent/awesome-design-md 项目中哪种风格适合后台管理项目？
- **答**：通用后台首选 Vercel 风格——中性灰阶 + hairline 细边框 + 克制的堆叠阴影，规范自带 `ex-app-shell-row`（侧边导航行）与 `ex-data-table-cell`（数据表格）等后台壳层示例，取其 in-app 尺度（6 px 按钮、8 px 卡片），营销 pill 不进后台。数据密集型（表格、日志、SQL）用 Supabase：白底近黑 + 单一祖母绿 CTA（#3ecf8e），6 px 方正圆角，本身就是数据库后台产品的语言。暗色专业工具风用 Linear：近黑画布（#010102）+ 单一薰衣草紫强调（#5e6ad2），层级靠面板抬升而非阴影。不适合的：PostHog（奶油色 + 吉祥物，规范明说产品内分析界面未采集）；汽车与消费品品牌风格（大图、氛围渐变，与高密度操作界面相反）。选型标准：后台界面以表格、表单、侧边导航、图表为主，须中性色为主、彩色仅用于状态与主操作、小圆角、完整字阶、数据用等宽字体。两套拉丁字体规范落在中文后台时，数字与拉丁字符按字阶走 Inter（Vercel/Supabase 推荐替代），中文回退系统字体。
