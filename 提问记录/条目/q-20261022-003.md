# 2026-10-22 · RPC 的含义、调用过程与协议边界

- **问**：什么是 RPC 协议？追问：它和 HTTP 接口调用有什么区别？
- **答**：RPC 是远程过程调用机制，具体协议规定业务方法、参数、结果、错误与请求响应匹配等规则；HTTP 是应用层通信协议，RPC 可以通过 HTTP 实现，gRPC 基于 HTTP/2，JSON-RPC 也允许以 HTTP 承载。资源式接口与方法式接口属于接口设计差异，代码生成等能力属于框架与工具差异，HTTP 接口也能采用 RPC 风格或借助 OpenAPI 生成客户端；两者都仍需处理网络故障，超时不代表服务端未执行，重试可能重复操作。
