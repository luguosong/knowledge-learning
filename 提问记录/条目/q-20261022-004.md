# 2026-10-22 · AI Agent 驱动海报、宣传册与封面制作的开源工具及工作流

- **问**：目前 AI Agent 驱动的海报制作、宣传册制作、封面设计与制作有哪些开源库，有哪些标准优秀的工作流？追问用两页软件地形功能介绍图明确：主要制作这样的产品介绍宣传海报。
- **答**：针对参考图这种软件功能介绍页，建议把真实界面截图、技术示意图、文字和版式分开制作，再由智能体统一排版：图片和 PDF 交付可用网页加 Playwright，需要可编辑演示源稿可用 PptxGenJS；先做概览页与功能分解页两种母版，再复用于其他模块。保留源稿、渲染检查与局部修订是工作流核心；下文通用工具表保留作其他交付条件的选项，上述优先级是工程判断，未做组合实测。

**库、引擎与应用的分工（2026-10-22 核实）。**

| 项目 | 许可 | 用途与边界 |
| --- | --- | --- |
| Playwright | Apache-2.0 | 真实浏览器渲染网页、截图及导出 PDF；保留网页源文件才能持续编辑结构。PDF 默认用打印样式，不代表自动符合印厂规范。 |
| Satori | MPL-2.0 | JSX 或对象树加 CSS 转 SVG；仅实现 CSS 的一定范围，默认将文字转路径，应保留源文件。当前 main 与旧缓存的布局和字体支持说明不同，使用时锁定发行版。 |
| sharp / resvg-js | Apache-2.0 / MPL-2.0 | sharp 处理图片并可将 SVG 转图片；resvg-js 是另一种 SVG 光栅化选择，不必同时引入。两者均不替代多页排版。 |
| Fabric.js / Konva.js | MIT / MIT | 自建画布编辑器的基础库，自身不提供完整设计智能体。Fabric 支持 JSON 和 SVG；SVG 往返并非完全无损。Konva 的常规 PDF 示例是将画布图片嵌入 PDF。 |
| Typst | Apache-2.0（开源编译器） | 代码化多页排版，支持中文字体和 CMYK；当前 PDF 导出规范列表未列 PDF/X。在线编辑器不属于同一开源范围。 |
| WeasyPrint | BSD-3-Clause | 网页代码分页为 PDF；70.0 稳定版列出 PDF/X-1a、X-3、X-4、X-5g，支持色彩配置和出血，但官方不保证仅选选项即可合规。 |
| Scribus | GPL-2.0-or-later | 桌面出版应用，通过 Python Scripter 填充模板与导出 PDF；支持 PDF/X-4、字体嵌入及出血设置，适合结合人工印前复查。 |
| ComfyUI / Diffusers | GPL-3.0 / Apache-2.0 | 分别提供节点化图像工作流及 Python 生成管线；智能体可调用 ComfyUI 本地 API。模型权重的许可和资源需求需另查。 |
| LangGraph | MIT | 可选的任务编排库，可保存状态、返工与暂停等待人工输入；其本身不是排版或绘图库。 |

**工程工作流建议（未做端到端实测）。**

1. 电子海报与封面：明确用途、尺寸、文字和品牌约束 → 规划视觉方向 → 生成或选取主图 → 用网页或矢量源文件独立排文字和标志 → 渲染预览 → 检查文字、裁切、遮挡与尺寸 → 修改源文件后重渲染 → 导出并保留源稿。文字与主图分离便于校对和局部修改。
2. 多页宣传册：先定内容提纲和每页任务 → 固定母版、字体、栅格、页码与图片规则 → 用 Typst 或 WeasyPrint 排版 → 渲染全部页面并查看整册缩略图和逐页详情 → 修复缺字、溢出、分页与风格不一致 → 再导出。
3. 印刷宣传册与完整书封：先取得印厂交付规格和封面模板 → 智能体准备素材与版式数据 → Scribus 脚本填充 → 逐页复查 → 按指定色彩、出血与 PDF 规范导出 → 印前检查和打样。封面包含封底、书脊和封面时，书脊尺寸依据最终页数、纸张与装订确定；不能统一套用出血量、裁切标记或 PDF/X 版本。

**参考图的具体流程与新增信源。**

- 根据用户图片观察，左页为概览：主标题、地形主视觉、软件菜单截图、三步示意与成果列表；右页为功能分解：数据准备、模型构建、场地分析。版式可以复用页眉页脚、颜色、字号、边距、分隔线与编号样式。不能仅凭图片确认原作者使用的软件或图片生成方式。
- 建议流程：整理功能名称与实际截图 → 选取产品真实渲染图或制作带说明的示意图 → 建立概览页与功能分解页母版 → 填充文字、图标与图片 → 检查截图可读性、中文换行、遮挡和功能对应关系 → 导出并保留源文件。流程为工程建议。
- PptxGenJS 为 MIT 许可，支持原生文字、形状、图片、母版与自定义页尺寸；可编辑性取决于对象类型，插入的截图内部文字仍属于图片。中文可指定 fontFace 和 lang，交付前应在目标软件复查字体和换行；指定字体名称不等于嵌入字体。
