# 2026-10-25 · Codex 如何设置无需审批的完整访问权限

- **问**：Codex 如何设置类似 Claude Code 的 bypass permissions on 完全权限？
- **答**：Codex 的 Full access 对应 approval_policy = "never" 与 sandbox_mode = "danger-full-access"；终端启动可用 codex --yolo（即 --dangerously-bypass-approvals-and-sandbox），桌面／IDE 在输入框下方权限菜单选择 Full access，CLI 会话内可用 /permissions。默认设置写入用户 ~/.codex/config.toml 顶层；never 仅关闭审批，必须同时取消沙箱才是完整访问，命令行参数、项目配置及组织强制要求仍可能影响结果。
