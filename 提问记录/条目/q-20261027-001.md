# 2026-10-27 · 在 Windows 本机打开 WSL 完整 Linux 桌面的方案选择

- **问**：wsl 可视桌面化远程方案；已澄清为在当前 Windows 上打开完整 Linux 桌面；追问：探测当前电脑 WSL 情况并给出建议；WSL 3.0.3.0 是否有对应的 WSL 3 发行版。
- **答**：延续 Xfce 加 xrdp、xorgxrdp 的组合建议：本机已运行 Ubuntu 26.04.1 LTS（WSL 2），systemd、WSLg 与镜像网络的基础已具备，但未安装 Xfce 和 xrdp，建议沿用现有发行版补齐桌面组件，配置本机回环端口供 mstsc 连接；WSLg 官方支持图形应用集成，Kali 的 Win-KeX 仍是特定发行版备选；另需区分 WSL 软件包版本 3.0.3.0、发行版运行架构 WSL 2 与 Linux 发行版 Ubuntu 26.04.1 LTS，微软当前文档列出的架构仍为 WSL 1 和 WSL 2，没有对应的 WSL 3 发行版。只读依赖模拟成功，计划新增 348 个软件包且无卸载，实际安装与桌面登录尚未验证；此前发现 `.wslconfig` 将 `autoMemoryReclaim=gradual` 放在 `[wsl2]`，已按用户要求于 2026-10-27 移入 `[experimental]` 并核对文件，其他配置已保留且已备份，尚未重启 WSL 或验证实际回收行为。
