# 2026-10-27 · WSL 内存占用、缓存回收与开发容器按需启动

- **问**：Windows 内存升高与 WSL 的关系；七个开发用 Docker 服务要求取消常驻，使用时再启动。
- **答**：本机 WSL 同时运行七个开发容器与多个 AI 进程，并保留文件缓存，`autoMemoryReclaim=gradual` 只针对缓存回收，不能替代停止不需要的应用，配置修改也须等 WSL 重启生效。已将 SQL Server、MySQL、Nacos、RabbitMQ、Redis、Qdrant、Ollama 的容器及对应 Compose 的重启策略设为 `"no"` 并正常停止，数据保留；WSL 内部已用由停用前约 7.1 GiB 降到约 3.0 GiB，剩余约 4.3 GiB 文件缓存及仍在活动的 AI 进程使宿主占用不会立即降至同一数字。
