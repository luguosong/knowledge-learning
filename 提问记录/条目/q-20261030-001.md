# 2026-10-30 · WSL 内 `文件名:Zone.Identifier` 文件的来历与处理

- **问**：仓库里为什么出现 `.gitignore:Zone.Identifier`、`AGENTS.md:Zone.Identifier` 这类文件。
- **答**：`Zone.Identifier` 是 NTFS 交替数据流（Alternate Data Stream，ADS），Windows 给网络下载文件附加的网页标记（Mark of the Web，MOTW），内容形如 `[ZoneTransfer] ZoneId=3`，3 对应 Internet 区域（URLZONE 枚举：0 本机、1 内网、2 受信任、3 Internet、4 不受信任）。这些文件在 Windows 侧下载获得 MOTW，再经资源管理器拖拽或复制进 `\\wsl$`；ext4 不支持 ADS，Explorer 写入该流时 WSL 未正确处理，把流物化成独立的 `文件名:Zone.Identifier` 文件。这是 microsoft/WSL #4609（2019 年开、2026-03 微软重开）记录的已知 bug，被打上 bug、file system、fixedininsiderbuilds 标签。本仓库实测 72 个，内容均为 `ZoneId=3`。处理：删除无害（`find . -name "*:Zone.Identifier" -type f -delete`）；`.gitignore` 加 `*:Zone.Identifier`；预防可把 `wsl.localhost` 加入本地 Intranet 站点，或在 Windows 侧先 Unblock。**2026-10-30 已清理**：经用户确认，删除 `/home/luguosong/code-wsl/personal` 下 4 个项目（视频制作 6022、知识学习 335、图片海报设计 11、书籍翻译 1）共 6369 个，删除前逐个校验内容均含 `ZoneTransfer`，删后复查为 0；同日清除 `code-wsl/company/uocs-project` 下 899 个，复查为 0。两处均逐个校验内容含 `ZoneTransfer`。
- **信源**：[一手·本机实测，2026-10-30] 仓库内 72 个该类文件的 `cat` 内容；[一手] [microsoft/WSL #4609](https://github.com/microsoft/WSL/issues/4609)；[一手] [URLZONE enumeration（Urlmon.h，MS Learn 归档）](https://learn.microsoft.com/en-us/previous-versions/windows/internet-explorer/ie-developer/platform-apis/ms537175(v=vs.85))；[二手·仅定位] [WSL #7456](https://github.com/microsoft/WSL/issues/7456)
