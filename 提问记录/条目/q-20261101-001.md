# 2026-11-01 · 什么是 DDNS

- **问**：什么是 ddns？
- **答**：DDNS 是"IP 会变、域名固定"矛盾的解法：客户端检测到公网 IP 变化，就自动更新 DNS 的 A/AAAA 记录，使域名始终指向当前 IP。标准协议是 RFC 2136 的 DNS UPDATE（1997 年，向权威服务器原子增删资源记录）；商用服务多用自家 HTTP API（如 Cloudflare 的 PUT /zones/{zone_id}/dns_records/{record_id}），客户端定时检测、变化即调用。前提是设备有公网 IP（动态亦可）；运营商 NAT（CGNAT）后无公网 IP 时 DDNS 无效，需改用内网穿透或私有组网（见 [[条目/q-20261013-001|内网穿透选型]]）。
- **信源**：[一手] [RFC 2136: Dynamic Updates in the Domain Name System (DNS UPDATE)](https://datatracker.ietf.org/doc/html/rfc2136)；[一手] [Cloudflare API · Update DNS Record](https://developers.cloudflare.com/api/resources/dns/subresources/records/methods/update/)
