# 浏览器扩展

## 综述

Chrome 网页配色扩展应按目标选择：Dark Reader 适合将明亮网页改为深色，并调节亮度、对比度和棕褐色滤镜；Midnight Lizard 适合自定义浅色或深色方案，以及背景和文字颜色。两者支持按网站设置。扩展受浏览器权限限制，不能修改 Chrome 设置页或 Chrome 网上应用店页面；具体网站的显示效果仍需实际确认。
