# 身份认证

## 综述

身份认证按密码存储、挑战响应、多因素、联邦登录和公钥凭据理解其暴露面与适用条件；WebAuthn 的域名绑定、公私钥边界不应泛化为所有攻击均被消除。Cookie、Session 与 JWT 属于会话或令牌层，JWT 是格式；Bearer 令牌泄漏后可能被冒用，DPoP 的限制也不能覆盖客户端已被控制的情况。OAuth 授权、OIDC 身份认证、会话管理和密码学基础分别学习，并以 Spring Security 集成与失败用例验证。成书按通用 API 安全、Java 工程与 OAuth 协议等视角分工，不能把系列书目当作 IAM 服务器总纲。
