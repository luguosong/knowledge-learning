# 远程办公

## 综述

美国云电脑可按月订阅并提供完整 Windows 桌面，但默认出口是云服务网络，不等于住宅 IP。市场上有商家出售标称住宅 IP 的远程桌面；线路性质目前只有商家声明，第三方平台是否接受该 IP 也无保证。若必须从真实家庭宽带出网，最可控的方式是在美国住宅部署自有电脑，再用远程桌面连接；办公资料能否放入第三方电脑还需符合所在单位的规定。远程桌面协议（Remote Desktop Protocol，RDP）负责传输远程画面与本地输入；它本身不决定远程电脑的上网出口或 IP 类型。商家将“RDP”用作远程电脑产品名时，应区分协议、电脑与网络线路。
