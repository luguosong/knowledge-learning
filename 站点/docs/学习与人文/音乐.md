## 陈宇任（Funck）的三类创作

陈宇任＝Funck，台湾词曲创作人，1976-02-07 生。作品分三块：

1. **为他人供曲**：胡歌〈逍遥叹〉（《仙剑奇侠传》插曲，词曲兼作）、王力宏〈心中的日月〉、S.H.E〈金钟罩铁布衫〉、萧亚轩〈来自第五大道的明信片〉、庾澄庆〈对峙〉、万芳〈月亮公园〉。
2. **个人专辑**：2006-09-22 发首张个人线上专辑《大家都爱孙中山》，联合浊水溪公社、自然卷等独立音乐人制作，风格为民谣／另类摇滚。
3. **乐团**：2012 年领衔台北公案乐团，作品含〈出草〉〈郊游〉〈爱情末班车〉〈子鱼〉等；获 2014 海洋音乐祭海洋之星大奖、StreetVoice 2014 年度十大新团。

- 《大家都爱孙中山》完整曲目未能从一手来源核实（百度百科页面 403）。
