# 扫地机器人

扫地机器人品牌排名的口径记录。主线：全球出货量份额排名及其统计口径。边界：出货量反映市场规模，不推导具体型号的性能、可靠性与售后质量。

## 全球品牌排名的统计口径

**结论**：按国际数据公司（International Data Corporation，IDC）发布的 2026 年第二季度数据（2026-09-15 发布），全球扫地机器人出货量份额前五依次为：石头 Roborock（23.7%）、追觅 Dreame（21.2%）、科沃斯 ECOVACS（16.2%）、小米 Xiaomi（9.8%）、MOVA（4.2%）。

引用任何排名必须同时注明三件事：统计期间、指标、品牌合并口径。缺一项，结论就可能变样。

```text
+ 排名口径（三者缺一不可）
|
+-- 统计期间 > 2026 年第二季度（IDC 2026-09-15 发布）
+-- 指标     > 全球出货量份额
+-- 品牌口径 > 追觅 Dreame 与 MOVA 分列
      |
      +-- 分列（IDC 图表口径）> Dreame 第二 21.2%，MOVA 第五 4.2%
      +-- 若两者合并          > 25.4% > 属另一合并口径，排名随之改变
```

**品牌口径的取舍**。IDC 图表将 Dreame 与 MOVA 分列；两者相加得 25.4%，会超过石头成为第一。合并与分列是两种口径，结论不同，引用时必须说明采用哪一种。

**限制**。这是季度出货量排名，只反映市场规模；不能直接推导具体型号的性能、可靠性或售后质量。
