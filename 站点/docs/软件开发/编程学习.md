# 编程学习

编程学习领域：以本人动手写、读、运行和调试为主线。视频、书籍、官方文档与 AI 按演示、系统理解、精确查阅与陪练分工；媒介本身不决定学习效果，输入后的检索练习才决定。边界：结论限于本次核实的一手来源。

## AI 时代学编程：看视频还是看书

**问题**：AI 时代学编程，看视频学和看书学，更推荐哪种？

**结论**：都不应作主要方式；主线是动手写项目。若分主次：以书和官方文档为主参照，视频只用于操作演示与建立第一遍直觉，具体疑问问 AI。媒介本身对学习结果差异很小；决定留存的是输入后的检索练习（Retrieval Practice），不是选哪种媒介。

### 机制：差异在加工方式，不在媒介

"看书比看视频记得牢"的说法需要修正：差异不在媒介本身，而在媒介默认诱发的认知活动。

```text
+ 媒介           + 默认诱发的加工                + 留存
+ 书 / 官方文档  + 生成式加工：改述、重组        + 更牢
+ 视频           + 转录式加工：听写、截图        + 较浅
+ 任意媒介       + 输入后检索练习：复现、问答自测 + 决定性
```

生成效应（Generation Effect，Slamecka & Graf 1978）支持：自己生成的内容记得更牢。

### 证据冲突：电脑笔记与手写笔记

- [一手] [Mueller & Oppenheimer 2014](https://journals.sagepub.com/doi/abs/10.1177/0956797614524581)：逐字转录的电脑笔记在概念题上劣于手写笔记。
- [一手] [Morehead et al. 2019 直接重复](https://link.springer.com/article/10.1007/s10648-019-09468-2)：未复现手写优势。

两说并存；不能把笔记工具直接当作学习效果的原因。

### 实操判据

- 笔记里有无自己生成的改述与结构。
- 复习时用问题-答案自测，不用重读。
- 输入后以复现、改述和问答自测检验理解。

## 李刚"疯狂"系列编程书籍的网上读者评价

**问题**：李刚的"疯狂"编程书籍系列，网上的真实评价如何？
