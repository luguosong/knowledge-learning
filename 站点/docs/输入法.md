# 输入法

开源拼音输入法选型。主线：找「打字顺便学外语」（候选词旁显示外语译词）细分里最完整的选择，并与通用成熟方案对比。边界：选型结论与活跃度数据，不含配置细节。待解：青简整句模型质量与长期维护前景。

## 打字顺便学外语：青简是该细分最完整的选择

结论按需求分岔（核实于 2026-10-30）：

```text
                  +-- 要译词学习（四平台、本地模型）------ 青简
[拼音输入法] -----+-- 要成熟通用 ----------------------- Rime + 雾凇拼音（rime-ice）
                  +-- 已用 Rime，只要中英日翻译混输 ---- rime-snomiao（Rime 配置）
```

- **打字顺便学外语**：选青简（qingjian）。该细分最完整：四平台、本地整句模型、五种目标语言。
- **纯粹好用的开源输入法**：选 Rime（中州韵）+ 雾凇拼音（rime-ice，20.0k★，GPL-3.0，词库长期维护）。最成熟的开源方案，但没有译词学习功能。
- **已用 Rime，只要中英日翻译混输**：选 rime-snomiao。不换引擎，加配置即得译词。

**青简是什么**：Rust 编写的开源拼音输入法，GPL-3.0-or-later，7.3k★。特色是候选词旁显示正在学习的外语译词（英语、日语、西班牙语、越南语、德语，可关闭），把背单词融入日常打字。具备整句输入、简拼、拼写纠错、双拼、五笔、本地整句模型与输入统计。拼音转换、词库查询、模型推理全部本地完成，无需账号。平台：macOS 13+、Windows 10/11（测试阶段）、Linux（Fcitx4/Fcitx5，需手动启动服务）、Android 8.0+（预览版）。

**直接同类**：

- rime-snomiao（79★）：Rime 配置形态的「词汇翻译混合输入」方案，方向为中/英/日（如会英语在学日语者输入英文得日文译词）。装在小狼毫（Windows）或鼠须管（macOS）上，Linux 标注 TODO。引用的讨论集中在 2023 年初，近期维护状态未确认。概念最接近，但规模、语言覆盖、平台与工程完整度都远弱于青简。
- 水杉输入法（MSIME）：第三方下载站称其为开源输入法、候选词旁显示译文、覆盖六平台。未找到官方仓库，**未核实**，不作为推荐依据。

**注意**：Rime 是输入法算法引擎，本身不是完整输入法，需配前端（Windows 小狼毫、macOS 鼠须管、Linux fcitx5-rime 或 ibus-rime）；rime-ice 是开箱即用的简体词库配置。
