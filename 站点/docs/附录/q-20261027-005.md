## 阅读规则

examples 的 data 才是示例对象；参考册整体不能发送给 MCP 服务器。内嵌输入请求只有 method 与 params，不加独立 JSON-RPC 信封。所有新增 x-description-zh、x-required-in-parent 与 fieldGuide 都是参考册注解，不是线上报文字段。

JSON Schema 中 required 表示直接父对象出现时的必填性；可选父对象未出现时，其内部必填字段无需单独出现。表格字段如果引用其他类型，沿类型标题继续查阅。保留官方英文 description 和完整 Schema 约束，以免简短中文概括丢失条件。

## 重要边界

本版顶层交互由客户端发起。服务器需要用户输入、根目录或模型采样时，在 resultType=input_required 的结果内返回 inputRequests；客户端以新请求 id 重试，提交 inputResponses，并原样回传 requestState。只有 tools/call、resources/read、prompts/get 支持这一中间结果。

订阅的确认是 notifications/subscriptions/acknowledged；最终 result 只在正常结束时返回。订阅通知携带 subscriptionId，进度和日志通知不属于订阅流。日志、根目录、采样在本版仍保留但已弃用。

工具执行失败通常使用 result.isError=true；协议级失败使用 error。缓存结果的 ttlMs 与 cacheScope 是必填项，ttlMs 的单位是毫秒。

## 具体 JSON 示例

以下是独立示例，不是一段依次执行的会话；MRTR 四个示例明确构成一个多轮流程。示例包含可选字段以便查阅。真实请求仅声明实际支持且本次需要的能力；演示场景中的 URL、游标和状态字符串不是可用于真实服务的凭据。

`io.modelcontextprotocol/protocolVersion` 是一个完整 JSON 键名。斜杠不产生嵌套对象；实际访问形如 `_meta["io.modelcontextprotocol/protocolVersion"]`。

### 示例业务字段

| 字段 | 含义 |
| --- | --- |
| `a` | 演示加法的第一个整数，非 MCP 内置参数。 |
| `b` | 演示加法的第二个整数，非 MCP 内置参数。 |
| `sum` | 演示加法结果，非 MCP 内置结果字段。 |
| `topic` | 示例提示模板要求的主题字符串。 |
| `language` | 补全上下文中已知的语言值。 |
| `path` | 资源模板 URI 中的路径变量。 |
| `label` | 表单示例的名称字符串。 |
| `count` | 表单示例的份数整数。 |
| `confirm` | 表单示例的确认布尔值。 |
| `plain` | 无独立显示标题的单选示例。 |
| `labeled` | 带显示标题的单选示例。 |
| `legacy` | 旧式枚举显示名示例。 |
| `tags` | 无独立显示标题的多选示例。 |
| `namedTags` | 带显示标题的多选示例。 |
| `email` | 表单示例的邮箱字段。 |
| `stage` | 日志 data 内的自定义阶段字段，不是 MCP 标准字段。 |
| `detail` | error.data 内的自定义错误详情。 |
| `header` | 示例 HeaderMismatchError 的 error.data 自定义字段，不是该错误要求的固定字段。 |
| `form / url / roots / sample` | 本例服务端给 inputRequests 分配的关联键；对应 inputResponses 必须使用相同键名。 |
| `com.example/category / com.example/tag` | 演示使用的厂商命名空间元数据；category=math 与 tag=demo 不具有标准含义。 |

官方类型：`MissingRequiredClientCapabilityError`。

```json
{
  "jsonrpc": "2.0",
  "id": 50,
  "error": {
    "code": -32021,
    "message": "缺少客户端能力错误",
    "data": {
      "requiredCapabilities": {
        "elicitation": {
          "form": {}
        }
      }
    }
  }
}
```

```json
{
  "jsonrpc": "2.0",
  "id": 50,
  "error": {
    "code": -32022,
    "message": "协议版本不支持错误",
```
